# Memory Card Example

A program that writes a save block to the memory card in slot 1, then reads it back. Provides a convenient save/load API that you can use in your projects.

Run `retrobuild` to compile `iso/PSX.EXE` and build a CD-ROM image (requires [mkpsxiso by Lameguy64](https://github.com/lameguy64/mkpsxiso)).
