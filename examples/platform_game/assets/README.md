# Assets

This example uses the following tools:

- [PNG2TIM](/tools/png2tim) to convert `character.png` to `character.tim` and `tiles.png` to `tiles.tim`
- [WAV2VAG](/tools/wav2vag) to convert `jump.wav` to `jump.vag` and `pickup.wav` to `pickup.vag`
- `level_editor.html` to make `level.bin` (simply open in the browser).
